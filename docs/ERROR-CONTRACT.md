# 오류 계약 — tab_explorer_templates

연결 계층과 갈아끼우는 자리가 돌려주는 오류는 두 갈래(`host_pywebview`, `host_electron`)에서 같은 구분값을 쓴다 (FR-37).
모든 오류는 `{ "ok": false, "error": { "code": "...", "message": "..." } }` 형태로 반환되며, 앱을 비정상 종료하지 않고 Shell에 알림으로 전달된다.

| 오류 코드 | 의미 | 발생 상황 |
| --- | --- | --- |
| `ROOT_ESCAPE` | 루트 경계 이탈 | 루트 밖 경로 (`..` 포함 경로, 루트 밖 절대 경로, 루트 밖을 가리키는 심볼릭 링크) 접근 시도 |
| `NOT_FOUND` | 대상 없음 | 요청한 경로 또는 파일이 파일시스템에 존재하지 않음 |
| `PERMISSION_DENIED` | 접근 권한 없음 | 파일 또는 디렉터리 읽기/접근 권한 부족 |
| `READ_FAILED` | 읽기 실패 | I/O 에러 등으로 인한 디렉터리 항목 읽기 실패 |
| `USER_CANCELLED` | 사용자 취소 | 폴더 선택 대화상자 등에서 사용자가 취소 |
| `UNSUPPORTED_TARGET` | 지원하지 않는 대상 | 지원하지 않는 파일 형식, 잘못된 대상 또는 미구현 도메인 호출 |

두 갈래의 연결 계층은 위 목록의 코드를 정확히 일치시켜 구현한다.
